## Эндпоинты подробно

### GET /service/test

Основной эндпоинт.

**Заголовки:**

| Заголовок | Обязательный | Описание                                  |
|-----------|:------------:|-------------------------------------------|
| X-User-Id | Да | Название неймспейса пользователя в gitlab |

**Пример запроса:**

```bash
curl -X GET https://alfa-campus-qa.ru/automation/api-service-checker/service/test \
  -H "X-User-Id: ваш-id"
```

**Успешный ответ (200):**

```json
{
    "service": "OK",
    "test": "OK"
}
```

**Ошибки:**

| HTTP-код | Код ошибки | Описание |
|----------|------------|----------|
| 400 | MISSING_HEADER | Не передан заголовок X-User-Id |
| 403 | USER_NOT_FOUND | Пользователь не зарегистрирован в системе |

Пример ошибки:

```json
{
    "error": "USER_NOT_FOUND",
    "message": "User 'unknown' is not registered"
}
```
